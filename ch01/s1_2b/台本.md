## 台词（46 句，1182 字）


### 开场：右边全是 0 → 齐次

- **D01** 大肥鱼：老师，上一节的方程组右边都有数。要是右边全是 0 呢？
- **C01** Claude：那它有个专门的名字：齐次线性方程组。今天就讲它。

### 零解（平凡解）与“非零解？”

- **C02** Claude：齐次，就是每个方程的常数项都是 0。比如这个方程组。
- **D02** 大肥鱼：那……全取 0 不就好了？x₁、x₂、x₃ 都是 0，左边自然等于 0。
- **C03** Claude：对！所以齐次方程组永远有解，至少有一个全 0 的解。
- **C04** Claude：这个解太理所当然了。教材叫它“平凡解”，同济叫它“零解”。
- **C05** Claude：真正值得问的是：除了零解，还有没有别的解？也就是非零解。

### 几何：两张过原点的平面交出一条直线

- **C06** Claude：来看图。三个未知数，每个方程就是空间里的一张平面。
- **C07** Claude：右边是 0，原点一定满足方程，所以每张平面都穿过原点。
- **C08** Claude：两张平面都过原点，又不重合，就一定交出一条直线。
- **C09** Claude：这条线上的每个点，都同时满足两个方程。原点只是其中一个。
- **D03** 大肥鱼：一整条线！那非零解就有无穷多个了？

### 消元验证：R₂ − 2R₁ → (−t, t, t)

- **C10** Claude：没错。消元验证一下：第二行减去第一行的两倍。
- **C11** Claude：得到 x₂ = x₃。x₃ 是自由变量，设它为 t，解就是 (−t, t, t)。

### t 取遍实数；第三张平面 → 只剩零解

- **C12** Claude：t 取遍所有实数，这些点正好排成那条交线。
- **D04** 大肥鱼：可要是再加一个方程，三张平面呢？
- **C13** Claude：一般来说，三张平面只在原点碰头，那就只剩零解。

### 定理 1.2.1：n > m ⇒ 有非零解（台阶证明）

- **C14** Claude：所以关键是方程个数 m 和未知数个数 n。教材定理 1.2.1 说：
- **C15** Claude：齐次方程组里，只要未知数比方程多，也就是 n > m，就一定有非零解。
- **D05** 大肥鱼：为什么“一定”？
- **C16** Claude：看台阶。每一行最多一个主元，m 行最多 m 个主元。
- **C17** Claude：可未知数有 n 个，比 m 多，所以至少剩下一个自由变量。
- **C18** Claude：让自由变量取 1，其余变量跟着算出来，就是一个非零解。

### 反例 + 同济的秩

- **G01** GPT：注意，反过来不成立：n ≤ m 也可能有非零解，比如三张平面恰好共用一条直线。
- **G02** GPT：同济用秩来说：系数矩阵的秩小于 n，就有非零解。秩后面再讲。

### 应用一：光合作用配平

- **D06** 大肥鱼：可右边全是 0，有什么用啊？看着好无聊。
- **C19** Claude：化学课配平方程式，就是在解齐次方程组。看光合作用。
- **C20** Claude：二氧化碳加水，生成氧气和葡萄糖。每种分子前面配一个系数。
- **C21** Claude：配平，就是两边每种原子一样多。先看碳：左边 x₁ 个，右边 6x₄ 个。
- **C22** Claude：氧：2x₁ + x₂ = 2x₃ + 6x₄。氢：2x₂ = 12x₄。
- **C23** Claude：把未知数都移到左边，右边全是 0：三个方程，四个未知数。
- **D07** 大肥鱼：齐次！而且 4 > 3，一定有非零解！
- **C24** Claude：对，定理保证能配平。消元以后，x₄ 是自由变量，x₁、x₂、x₃ 都等于 6x₄。
- **C25** Claude：取 x₄ = 1：六个二氧化碳加六个水，生成六个氧气和一个葡萄糖。
- **D08** 大肥鱼：那零解呢？零个二氧化碳加零个水……
- **G03** GPT：就是什么反应都没发生。数学上成立，化学上没意思。

### 应用二：Leon 车流（图 1.2.2）

- **C26** Claude：再看一个右边不全是 0 的例子：市中心四个路口的车流。
- **C27** Claude：每个路口，开进来的车等于开出去的车。四个路口，就是四个方程。
- **C28** Claude：比如路口 A：x₁ + 450 = x₂ + 610。
- **C29** Claude：化成简化行阶梯形，最后一行全是 0，x₄ 是自由变量。
- **C30** Claude：x₁、x₂、x₃ 都等于 x₄ 再加一个常数。
- **D09** 大肥鱼：那每条路上到底有多少车？
- **C31** Claude：光靠四个路口，算不出来。只要再测一条路，比如 x₄ = 200……
- **C32** Claude：其余三条马上就知道：530、370、410。

### 总结

- **D10** 大肥鱼：我来总结！齐次方程组一定有零解；未知数比方程多，就一定有非零解！
- **C33** Claude：完全正确。下一节，我们把方程组写成“矩阵乘向量”，换个角度看它。
