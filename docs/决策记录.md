## 2026-11-13 · 30 秒样片

| 决策 | 结论 | 原因 |
|---|---|---|
| 大圆舞台上的网格颜色 | 变换后网格用 `paper_hi` 奶油色细线，原始网格用 `ink` 12% 虚影；大圆填色 `peri` 与 `paper` 22% 混合 | 视觉规范原定"变换后网格 peri"，但网格画在 peri 大圆里会看不见；奶油线在蓝圆上更像丝网印刷 |
| 箭头与公式在色块上的可读性 | 箭头、TeX 标签加 `paper_hi` 外描边（halo） | ĵ 青绿与长春花蓝明度接近 |
| 字幕字体 | 拉丁字母优先用 Noto Sans（LA-Latin），中文回落思源黑体 | 思源缺 ĵ |
| 3D 进场 | three.js 相机从正上方俯视（与 2D 画面对齐）转到斜视，2D 层同时淡出 | 让观众感到"同一张平面立起来了" |
| 样片时长 | 31.3 s（8 句，人声 23.2 s） | — |
