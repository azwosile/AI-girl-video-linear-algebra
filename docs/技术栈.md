# 技术栈（2026-11-13 定稿 v1）

## 1. 总体结构：一条时间轴、一个渲染器、三种画面能力

```
lines.py ─► script.json ─► GPT-SoVITS(9880) ─► qa_asr ─► prep(提速/测时长) ─► durations.json
                                                                                  │
   tex_build.mjs（TeX → SVG 路径缓存）─────────────────────────────┐              │
                                                                   ▼              ▼
  ┌──────────────────── engine/（全项目唯一一份）──────────────────────────────────────┐
  │ core/timeline.js   计划(PLAN) → 按实测时长排轴；缓动；镜头（推拉/平移/聚焦，2.5D 视差）│
  │ core/stage.js      主 Canvas 2D（1920×1080），合成所有图层                          │
  │ la2d/              2D 线代组件（网格、向量、变换、span、行列式面积、消元表…）        │
  │ la3d/              three.js 场景（ℝ³ 网格、平面、体积、特征方向），离屏 WebGL 合成    │
  │ tex/               TeX 路径缓存加载、公式揭示、按字形匹配的公式变形（TransformMatchingTex）│
  │ style/             视觉 token（见 视觉规范.md）与构成主义母题（大圆、斜切、星点、竖线） │
  │ cast/              角色剪纸动画（呼吸、眨眼、口型三帧、入场、探头、圆窗）            │
  │ fx/                克制特效（墨迹揭示、纸片翻转、冲击环）                            │
  │ audio/             音效登记 → timeline.json                                          │
  └─────────────────────────────────────────────────────────────────────────────────────┘
                     │ window.renderAt(t)（纯函数，任意帧可单独重渲）
                     ▼
  render.py：Playwright + Chrome，N 个页面分块并行逐帧 → h264_nvenc 分块 → 无损 concat
                     ▼
  mix.py（人声 + 音效 + BGM，闪避）→ loudnorm −16 LUFS / −1.5 dBTP → 成片 mp4 + SRT
```

**原则**
- **确定性**：任何画面状态只由 `t` 决定，不依赖上一帧；随机数一律用固定种子。
- **单一时间轴**：2D、3D、公式、角色、音效全部挂在同一个 `PLAN` 上。不允许出现「Manim 一条轴，网页一条轴」需要手工对齐的情况。
- **引擎不复制**：渲染时用本地 HTTP 服务把**项目根目录**作为站点根，各段 `index.html` 用 `/engine/...` 引用。引擎改动用 git 管理，不再每段 `cp core.js`。
- **素材自包含**：只引用本项目 `assets/` 内的文件，不引用其他课程目录。

## 2. 选型明细

| 环节 | 选型 | 版本/位置 | 说明 |
|---|---|---|---|
| 2D 动画 | Canvas 2D | Chrome 157 | 网格变换本质是对线段集合乘矩阵，Canvas 实现最快。矩阵插值用 `(1−s)I + sA`（与 3B1B 一致），旋转类变换可选按极分解插值，避免中途压扁 |
| 3D 动画 | three.js | 锁定一个 r1xx 版本放 `engine/vendor/` | 离屏 `WebGLRenderer({preserveDrawingBuffer:true, antialias:true})`，每帧由 `t` 设定相机与对象后 `render()`，再 `drawImage` 合成进主 Canvas。线条用 `Line2`（粗线），平涂材质 `MeshBasicMaterial` 保持海报感 |
| 公式 | MathJax 3（node，`mathjax-full`），TeX → SVG | `engine/vendor/` + `pipeline/tex_build.mjs` | 构建期扫描台词与场景里的 `tex\`...\`` 字符串，输出 `tex_cache.json`（每个字形的 path、位置、TeX 源片段 id）。运行时转成 `Path2D` 绘制，可以描边揭示、按字形逐个变形。TinyTeX 保留作备用（`E:\AI\TinyTeX`） |
| 中文字体 | 思源宋体（标题）、思源黑体（字幕、标签）、得意黑（花字点缀） | `assets/fonts/`，子集化 woff2 | 均为 SIL OFL。参考图的标题是加点衬线体，对应思源宋体加字距 |
| 角色 | Arena 生图（构成主义三色平涂）→ 抠图 → 分层（身体 / 头 / 眼 / 嘴 / 手臂） | `assets/characters/` | 见 视觉规范.md 第 5 节 |
| 配音 | GPT-SoVITS v2Pro，API 9880 | `E:\AI\TTS\GPT-SoVITS-v2pro-20261006nvidia50x0` | 参考音在 `assets/voice_ref/`。见 角色与配音.md |
| ASR 复核 | funasr Paraformer + 无调拼音比对 | 沿用微积分课 `qa_asr.py` | 相似度 < 0.85 标 ⚠，人工复听 |
| 渲染 | Python + Playwright（`uv run --with playwright`），Chrome channel | `pipeline/render.py` | 1080p60。按块（每块约 20 s）多进程并行，每块单独编码再 concat |
| 编码 | 预览 `h264_nvenc -preset p5 -cq 21`；成片 `libx264 -crf 16 -preset slow` | FFmpeg 9.0.2 | 60 fps 帧数翻倍，预览一律用 NVENC |
| 混音 | 沿用微积分课 `mix.py` 参数 | | BGM RMS 0.12×0.30，人声闪避 60% |
| 字幕 | 画面内烧录 + 同时导出 `.srt` | | 字幕写真实符号，朗读稿写读法 |
| AE | 片头、章节卡、转场模板，输出 PNG 序列（带 alpha），由 timeline 按时间贴入 | AE 已运行，**需另开 AE MCP** | AE 不承担任何数学内容 |
| PR | 审片、章节标记、导出交付 | Premiere 26.0，MCP 已连接 | 不承担主时间轴；成片必须能由代码完整重建 |
| Manim | 备用 | `TOOLS\manim-env`（CE 0.22） | 仅当 three.js 难以实现时，预渲染透明序列贴入 |
| 版本管理 | git | | `out/`、`frames/`、`vo/`、`vo48/`、`参考书籍和PPT/` 不进库 |

## 3. 分段工程结构

```
ch01/
├─ chapter.json            章名、分段表、接力卡路线图
├─ shared/                 本章专用组件（只放确实只有本章用的）
└─ p1/
   ├─ lines.py             台词源（唯一真源）：说话人、字幕文本、朗读文本、立绘表情、BEAT
   ├─ scene.js             本段画面：只写 PLAN 与场景函数，组件一律来自 /engine
   ├─ index.html           引用 /engine/*.js 与 ./scenes.js
   ├─ tts_override.json    个别句的 seed / 情绪覆盖
   ├─ vo/ vo48/            配音（不进库）
   └─ out/                 timeline.json、sheet.jpg、video.mp4、成片（不进库）
```

统一入口（替代每段一份 build.sh）：
```bash
pipeline/build.sh ch01/p1 lines      # 生成 script.json / lines.json
pipeline/build.sh ch01/p1 tts        # 配音（缺失句）
pipeline/build.sh ch01/p1 asr        # 逐句复核
pipeline/build.sh ch01/p1 sheet      # 联系表（逐句一帧）
pipeline/build.sh ch01/p1 preview    # 720p30 NVENC 快速预览
pipeline/build.sh ch01/p1 final      # 1080p60 成片 + SRT
```

## 4. 节奏与质检硬指标（继承微积分课，按线代调整）

| 指标 | 上限/要求 |
|---|---|
| 静音占比 | ≤ 15% |
| 单次无人声 | ≤ 1.5 s（思考题 ≤ 4 s，期间必须有动画） |
| 数学区无变化 | ≤ 2 s |
| 语速 | 标准 ≈ 280 字/分；难点 ≈ 250 字/分（靠删字加动画，不靠拉慢） |
| 数学区面积 | ≥ 画面 60%（角色缩小时） |
| 正文公式字号 | ≥ 56 px（1080p），字幕 ≥ 40 px |
| 同屏强调色 | ≤ 3 |
| 响度 | −16 LUFS，峰值 ≤ −1.5 dBTP |

每次出片：`check_pace.py` 通过 → ASR 通过 → 联系表目检 → 数学复核（第二遍独立核对每个例题、矩阵乘积、行变换）→ 完整观看。

## 5. POC 结果（2026-11-13，30 秒样片 `ch01/p0_sample`）

| 项目 | 结果 |
|---|---|
| three.js 离屏渲染 | ✅ 本机 Chrome（D3D11）无头渲染正常，与沙箱 SwiftShader 结果一致；单帧（含 2D 合成 + JPEG 编码）约 35 ms |
| MathJax 路径缓存 | ✅ `pipeline/tex_build.mjs` 输出逐字形 Path2D；`\class{名}{…}` 打标签，支持逐字书写、分组淡入、分组飞行、`morphTex` 两式变形；`bmatrix` 正常 |
| 1080p60 并行渲染 | ✅ 31.3 s / 1877 帧，3 进程 73 s（约 25 帧/秒）。按此速度 10 分钟段约 24 分钟，后续用 4–5 进程逼近 15 分钟目标 |
| 混音 / 响度 | ✅ `mix.py` + loudnorm：−15.8 LUFS，峰值 −5.5 dBTP |
| 字体 | ✅ 思源宋体 / 黑体可变字体固定字重后按用字子集化（共约 350 KB）；思源缺 ĵ 与组合抑扬符，补 Noto Sans 拉丁版兜底（`LA-Latin`） |
| 角色分层与口型 | ⏳ 样片只用整张立绘 + 配音包络弹跳；分层（眼 / 嘴 / 前臂）留到第 1 章正片 |

### 引擎目录（已实现）

```
engine/
├─ core/   util.js（缓动、矩阵插值）· timeline.js（按实测时长排句、登记音效）· stage.js（纸纹、资源）· boot.js（加载 → window.renderAt）
├─ style/  tokens.js（色板 / 字体）· motifs.js（四角星、加点标题、角标、斜切色块）
├─ tex/    tex.js（TexBank：逐字形绘制、reveal、分组 alpha/位移、morphTex）
├─ la2d/   plane.js（网格 / 坐标轴 / 直线在矩阵 M 下变换，箭头、引导弧、落点、脉冲环）
├─ la3d/   space3d.js（three.js：变换网格、单位立方体三色面、基向量箭头、球坐标相机）
├─ cast/   cast.js（剪纸入场 / 退场、包络弹跳、呼吸、纸片投影、身后色圆；字幕条）
└─ vendor/ three（r170 + lines 插件）
```

### 出片命令（Git Bash，项目根目录）

```bash
node pipeline/tex_build.mjs ch01/p0_sample                         # tex.json → tex_cache.json（需 pipeline/ 下 npm i）
uv run --with fonttools --with brotli python pipeline/fonts.py     # 新增文字后重做字体子集
uv run --with playwright python pipeline/render.py ch01/p0_sample --channel chrome --frames 3 8.5 14   # 抽帧检查
bash pipeline/build.sh ch01/p0_sample --jobs 3                     # 渲染 → 混音 → loudnorm → SRT → 720p 预览
```
预览：项目根目录 `python -m http.server`，打开 `/ch01/p0_sample/index.html`（空格播放，←/→ 逐 0.1 s，`?t=12.5` 跳转）。
