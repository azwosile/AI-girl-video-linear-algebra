1. 数学区偏小（约 30%），公式 20–28 px → 本项目数学区 ≥ 60%，公式 ≥ 56 px
2. 没有真正的 LaTeX → MathJax 路径缓存
3. 没有真 3D → three.js
4. 引擎每段复制、kit 拼接成 95 KB → 引擎只有一份，按路径引用
5. 参考音跨项目引用 → 复制进 `assets/voice_ref/`
6. tools/ 堆了 70 多个 `_job_*.sh` → 统一 `pipeline/build.sh <段> <步骤>`
7. 只有烧录字幕 → 同时输出 SRT
