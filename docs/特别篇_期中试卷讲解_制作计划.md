## 0. 定位与范围

**目标**：帮助本学期期中复习。把 9 份卷子提炼成**约 60 道题（约 110 个小问）**。分 **7 集特别篇、43 段**，总长约 **4.5 小时**。每集 27–50 分钟，可以单独看。

**考试范围判断**
- 2023–24、2024–25、2025–26 三份最新期中卷都只考 Leon 第 1–3 章：方程组与矩阵、行列式、向量空间。
- 所以特别篇以第 1–3 章为主。
- 超纲题默认不讲，包括 2015–16 第 5、7–9 题和 2022–23 第 1(3)(4)(6)(7)(9)、4–7 题，涉及正交、特征值、二次型。
- 如果需要，可以以后另做“特别篇 8：期末预告”（见 §11 待确认）。

**考点频率**（按“出现过的卷数 / 7 份真期中卷”统计；2015–16 和 2022–23 不计入分母）：

| 考点 | 频率 | 典型分值 | 对应特别篇 |

- 配音：C c_ref ×1.10；G G07_01 ×1.12；D dwg_ ×1.08。tts 用 `tts_la.yaml`。

## 7. 工序（与第四章相同）

lines.py → g2p_lint → mathcheck → tts（短分句防吞字）→ prep → tex_build → cuechk → dryrun → **立即 sync 到主机** → 本地抽帧 → 主机 ASR → 出片 → QA → 合集 → git → 报告。

- **mathcheck 新增格式**：
  - `lu`：{A, L, U}，校验 L 为单位下三角且 LU=A。
  - `inv`：{A, A⁻¹}。
  - `trans`：{E, F, S, 约定}，按约定校验 S=F⁻¹E 或 E⁻¹F。
  - `rrefback`：{U, 已知列, 求得列, b}，校验 rref(A)=U。2017–18 第 8 题标记 `expect_conflict`。
- **内存**：GPT-SoVITS API 用完立即结束。RAM 15.4 GB，PR 和 AE 不与 TTS 同时开。
- 段长比正片长（最长 14 分钟），出片时 `--jobs 2`、libx264（后台任务里 NVENC 会失败）。

## 10. 要不要开 PR / AE 的 MCP

**写计划稿阶段都不需要。** 正式制作时：

- **AE（Surehand MCP）**：**可选**。只在你想要比引擎内更华丽的“特别篇 N”片头或转场时开，一次做好模板，七集复用。所有讲解动画都在自家引擎里完成，不依赖 AE。
