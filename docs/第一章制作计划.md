## 2. 每段工序（带关卡，按顺序）

1. **大纲**：逐条摘 Leon 原文的定义 / 定理 / 例题与同济对应条目 → 设计 3B1B 式画面 → 列「大肥鱼的问题」。
2. **台词** `lines.py`（大肥鱼一问 → Claude 连续讲 → GPT 最多一段快招 → 大肥鱼复述）。
3. **数学复核**（新增 `pipeline/mathcheck.py`）：例题矩阵、行变换、乘积统一写在 `math.json`，`scene.js` 读同一份数据，sympy 独立验算。屏幕上的数字和验算用的是同一份数据。
4. **读音关**（新增，必须 PASS）：`$PY pipeline/g2p_lint.py ch01/<段>`。
5. **配音**（GSV API 9890，`tts_la.yaml`）→ `asr.py` → 亲自复听 ⚠ 句与时长异常句 → 换种子写入 `tts_override.json`。
6. **画面**：`scene.js` → `test/dryrun.mjs`（无浏览器排错）→ 抽帧联系表 → 目检（手指数、字号、重叠、同屏强调色 ≤3）。
7. **节奏关**：补写技术栈里写了但还没有的 `check_pace.py`（静音占比、单次无人声、数学区静止 > 2 s）。
8. **出片**：`prep.py` → `build.sh --jobs 3 --enc libx264`（实测约 20 帧/秒/进程，3 分钟片约 3 分钟渲染）→ 响度 −16 LUFS → SRT。
9. **AE（Surehand MCP，已连通）**：做一套章节卡 / 片头模板，输出带 alpha 的 PNG 序列，由 timeline 贴入；AE 不碰数学内容。
10. **PR**：`premiere-pro` MCP 目前状态 **error、0 个工具**，需要你在本机重启 Premiere 面板 / MCP 后再接；只用于合集与章节标记。
