## 2. 各段要点

- **7.1a 电脑里的数**
  - 开头接住第六章片尾的问题：“特征值、奇异值，计算机到底怎么算？”π 的 20 位真值被截成 3.1416，引出“每一步都舍入”。
  - 浮点数定义 ±(d₁/β + ⋯ + dₜ/βᵗ) × βᵉ、规格化；例 1、例 2。
  - 例 3：β = 10、t = 1、指数 −1 到 1，一共 55 个数画在数轴上。0 附近 18 个绝对值小于 0.1，越往外越稀，1 和 2 之间一个都没有。
  - 绝对误差 / 相对误差（表 1）；例 4：11.31 的二进制，小数部分“乘二取整”逐行展开。
  - 例 5：fl 加法与乘法，a′ = 0.263 × 10⁴、b′ = 0.446 × 10¹。机器精度 ε = ½β¹⁻ᵗ，fl(a′∘b′) = (a′∘b′)(1 + δ)。
  - 例 7：IEEE 754 单精度 32 位串逐位点亮 → 17.5；双精度 ε = 2⁻⁵² ≈ 2.22 × 10⁻¹⁶。
  - 同济对照：同济没有这一章，所有计算默认精确。
- **7.1b 抵消与不稳定**
  - 浮点加法不满足结合律：三位十进制 (1.00 + 0.004) + 0.004 = 1.00，而 1.00 + (0.004 + 0.004) = 1.01；双精度 (0.1 + 0.2) + 0.3 ≠ 0.1 + (0.2 + 0.3)。
  - 例 6：c = 3.4215298、d = 3.4213851，六位十进制下 c′ − d′ = 0.000140，真值 0.0001447，相对误差 3.2%，放大了一万倍以上。前四位逐个“熄灭”。
  - 例 8：x² − (10⁷ + 10⁻⁷)x + 1 = 0。直接用求根公式算小根错 0.35%；改用 r₂ = c/(a r₁)，完全正确。
  - 病态问题：x¹⁰ = 0 的常数项改 10⁻¹⁰，十个根从 0 跑到半径 0.1 的圆上。
  - 本章路线图：消元与主元 → 条件数 → 正交变换。
  - 同济对照：二次方程的韦达定理 x₁x₂ = c/a，正是稳定算法用的那条关系。
- **7.2 消元就是 LU**
  - 例 1：A = (2 3 1; 4 1 4; 3 4 6)，乘数 2、3/2、1/10 依次落进被消掉的格子，长出 L；U 的对角元 2、−5、4.3。
  - 初等矩阵的逆按顺序乘回去，乘数正好落在 L 的下三角。
  - 例 2：b = (−4, 9, 0)，前代 y = (−4, 17, 4.3)，回代 x = (2, −3, 1)。
  - 运算量：乘除 ⅓n³ + n² − ⅓n，用“金字塔体积”演示；n = 1000 约 3.3 亿次。
  - 换 b 只要 n² 次；(AB)x 与 A(Bx) 的计算量差五百倍。
  - 同济对照：第三章用初等行变换解方程组，和这里的消元一样，只是没有写成 LU。
- **7.3 主元策略**
  - 例 1：用行号向量 p 代替真的换行，PA = LU，L = (1 0 0; 3 1 0; 2 −4 1)，U = (2 −1 1; 0 −1 −1; 0 0 −5)。
  - 例 2：c = Pb → 前代 → 回代，x = (1, 1, −2)。
  - 例 3：0.0001x₁ + 2x₂ = 4，x₁ + x₂ = 3。三位十进制不换行，乘数 10000，x₁ 错 100%；换行后乘数只有 0.0001，答案 (1, 2) 完全正确。
  - 部分主元 |lᵢₖ| ≤ 1；完全主元更稳，但搜索代价大。
  - 同济对照：同济手算喜欢挑 1 当主元，为了少出分数；电脑正相反，挑绝对值最大的。
- **7.4a 矩阵范数**
  - Frobenius 范数；相容性 ‖AB‖ ≤ ‖A‖‖B‖。
  - 几何：单位圆被 A 变成椭圆，最长半轴就是 ‖A‖₂ = σ₁（定理 7.4.3，A = (2 1; 1 3)，σ₁ ≈ 3.618）。
  - 1-范数的单位“圆”是菱形，∞-范数的是正方形，经 A 变形后最远的顶点决定范数：最大列和 / 最大行和。记法：“1 竖着写像一列，∞ 横着躺像一行”。
  - 例 1：四阶矩阵，‖A‖₁ = 14，‖A‖∞ = 15。
  - ‖Ax‖ ≤ ‖A‖‖x‖；‖I‖₂ = 1、‖I‖F = √n；正交矩阵 ‖Q‖₂ = 1。
  - 同济对照：同济不讲矩阵范数，只在第五章讲过向量长度和正交矩阵保持长度。
- **7.4b 条件数**
  - 例 2：系数 2.0005 存成 2.001，只改 0.025%，解从 (1, 2) 跳到 (2, 1)。画成两条几乎平行的直线。
  - 例 4：残差只有 1/18，误差却是 100%。残差小 ≠ 误差小。
  - (1/cond)‖r‖/‖b‖ ≤ ‖e‖/‖x‖ ≤ cond·‖r‖/‖b‖；例 3 cond∞ = 24，例 4 恰好顶到上限 4/3。
  - cond₂ = σ₁/σₙ：椭圆越扁越病态。
  - 希尔伯特矩阵：cond₂(H₄) ≈ 1.6 × 10⁴，H₁₂ ≈ 1.6 × 10¹⁶；双精度解 H₁₂x = b 错 28%。
  - 经验法则：大约丢掉 log₁₀ cond(A) 位；例 5：100 阶上三角矩阵 cond∞ ≈ 6.34 × 10³¹。
  - 同济对照：行列式不为零 ⇒ 唯一解，但行列式不能衡量病态（每个方程乘 10，det 变 100 倍，条件数不变）。
- **7.5 正交变换**
  - ‖Qe‖₂ = ‖e‖₂：误差圆转一圈还是同样大的圆。
  - Householder H = I − 2uuᵀ：镜子放在 x 和 αe₁ 正中间；α 与 x₁ 异号，避免第 1 节的抵消。
  - 例 1：x = (1, 2, 2)，α = −3，v = (4, 2, 2)，β = 12，Hx = (−3, 0, 0)。例 2：嵌进右下角。Householder QR 约 ⅔n³。
  - Givens：例 3 (−3, 4) → (5, 0)（旋转与反射两种写法）；例 4 (5, 8, 12) 只转第 1、3 坐标 → (13, 8, 0)。满矩阵约 4/3 n³，适合快三角形的矩阵。
  - 同济对照：第五章的施密特正交化是一个个“造”正交向量；Householder 和 Givens 反过来，用正交矩阵去“消零”。
- **7.6 特征值问题**
  - 定理 7.6.1：min|λ′ − λᵢ| ≤ cond₂(X)‖E‖₂。对称矩阵 cond₂(X) = 1，很稳；A = (1 1; ε 1) 只扰动 10⁻¹⁰，特征值变成 1 ± 10⁻⁵。
  - 幂法：例 1 A = (2 1; 1 2)，u₀ = (2, 1)，向量一次次被拉向 (1, 1)，λ 的近似 5 → 2.8 → 2.93 → 2.976 → 2.992；收敛比 |λ₂/λ₁| = 1/3。
  - QR 算法（Francis，1961）：Aₖ₊₁ = RₖQₖ = QₖᵀAₖQₖ，正交相似、误差不放大；例 2 非对角元 0.6 → 0.22 → 0.074 → 0.025，对角元逼近 3 和 1。
  - 实用两招：先化成 Hessenberg / 三对角，再加原点平移。
  - 同济对照：相似矩阵有相同特征值；QR 算法就是造一串相似矩阵，让它慢慢变成三角形。
- **7.7 最小二乘问题**
  - 正规方程把条件数平方：cond(A) ≈ 2.4 × 10⁶ 的 A，cond(AᵀA) ≈ 6 × 10¹²，丢掉的位数翻倍。
  - 经典 Gram–Schmidt 在三列几乎相同时 q₂·q₃ = 0.5（夹角 60°）；修正 GS（算法 7.7.1）只有 10⁻¹⁶。
  - Householder QR：QᵀA = (R₁; O)，c = Qᵀb，R₁x = c₁，残差就是 ‖c₂‖。
  - 秩亏：A⁺ = VΣ⁺Uᵀ；定理 7.7.1：A⁺b 是范数最小的最小二乘解，几何上是原点到解集直线的垂足。
  - 奇异值很稳：|σᵢ − ωᵢ| ≤ ‖A − B‖₂；实际用 Golub–Reinsch 迭代。
  - 同济对照：同济第四章“通解 = 特解 + 齐次通解”就是这里那条解集直线，伪逆挑的是和齐次解正交的那个特解。
- **复习 · 判断题 10 道**
  - 题目：Test A 第 1–10 题。大肥鱼答对 **5 / 10**。
  - 正确答案：F F F T F F T F F F。
  - 大肥鱼错在第 2、3、5、6、10 题，正好对应本章五句话：运算顺序决定计算量、稳定 ≠ 准（病态）、非对称特征值敏感、不求逆、伪逆在秩变化处不连续。
- **复习 · 计算题（上）**：Test B 第 1–5 题
  - TB1：(AB)x 要 n³ + n² 次乘法，A(Bx) 只要 2n²。
  - TB2：部分主元，主元 4、再选 2，P 按行 2、3、1；L = (1 0 0; ¼ 1 0; ½ ½ 1)，U = (4 4 8; 0 2 2; 0 0 1)；两个右端 x = (−3, 1, 1)、(5, 3, −3)。
  - TB3：‖Q‖₂ = 1，‖Q‖F = 2。
  - TB4：4 阶希尔伯特矩阵，‖H‖₁ = 25/12，‖H⁻¹‖₁ = 13620，cond₁ = 28375，相对误差 ≤ 2.04 × 10⁻⁹。
  - TB5：cond∞ = 5 × 10⁶，15 位十进制，相对误差 ≤ 5 × 10⁻⁸，大约 7 位准确数字。
- **复习 · 计算题（下）与全课收尾**：Test B 第 6–10 题

  - TB7：B = RQ = QᵀAQ，特征值相同，特征向量差一个 Qᵀ，这就是 QR 算法的每一步。
  - TB8：A = (1 2; 4 3)，幂法五次 7、4.71、5.06、4.99、5.0024 → λ₁ = 5，x₁ = (1, 2)；另一个特征值 −1。
