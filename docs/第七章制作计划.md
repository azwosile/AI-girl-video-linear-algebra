## 0. 主线

**一句话主线：电脑只有有限位数字。** 每一步都会舍入，所以：
- 算法要稳定：主元要选大的，变换尽量用正交的。
- 问题本身要看条件数：条件数大，谁来算都不准。

**几何线（3B1B）**
- 数轴上的浮点数：55 个一位浮点数挤在 0 附近、越往外越稀。
- 抵消：两个很接近的数相减，前面几位全部抵消，剩下的有效数字只剩一两位。
- 消元 = LU：乘数存进被消掉的位置，下三角 L 一格格长出来。
- 运算量：n³/3 的立方体切片。
- 小主元：两条直线几乎重合时，交点被“甩”飞；换行后乘数 ≤ 1。
- 范数：单位圆 / 菱形 / 正方形被 A 变形，最远点到原点的距离就是 ‖A‖。
- 条件数：两条几乎平行的直线，系数动 0.025%，交点从 (1, 2) 跳到 (2, 1)。
- 残差小 ≠ 误差小。
- Householder：沿 v 的法平面做镜面反射，x 落到 e₁ 轴上；Givens：转一个角，第二个坐标归零。
- 正交变换不放大误差：误差圆转一圈仍是同样大小的圆。
- 幂法：向量反复乘 A 再缩放，扇形一样收向主特征方向。
- QR 算法：Aₖ 的非对角元一次比一次小，对角元逼近特征值。
- 最小二乘：正规方程把条件数平方；SVD 的伪逆给出解集直线上离原点最近的点。

**代数线（Leon）**
- **§7.1 浮点数**
  - 定义 ±(d₁/β + ⋯ + dₜ/βᵗ) × βᵉ；规格化；例 2；例 3（t = 1 的 55 个数）；绝对误差 / 相对误差（表 1）。
  - 例 4：11.31 的二进制；例 5：fl 加法与乘法（a′ = 0.263 × 10⁴，b′ = 0.446 × 10¹）。
  - 机器 ε：fl(1 + ε) > 1，ε = ½β¹⁻ᵗ，双精度 2⁻⁵² ≈ 2.22 × 10⁻¹⁶。
  - 例 6：抵消；例 7：IEEE 单精度位串 → 17.5；例 8：二次方程的稳定求根。
- **§7.2 高斯消元**
  - 例 1 A = (2 3 1; 4 1 4; 3 4 6) = LU，乘数 2、3/2、1/10，U 的对角元为 2、−5、4.3。
  - 例 2 前代、回代，x = (2, −3, 1)。
  - 运算量：乘除 ⅓n³ + n² − ⅓n，加减 ⅓n³ + ½n² − ⅚n。
- **§7.3 主元策略**
  - 例 1 用 p 向量记录行交换，PA = LU，L = (1 0 0; 3 1 0; 2 −4 1)，U = (2 −1 1; 0 −1 −1; 0 0 −5)。
  - 例 2 x = (1, 1, −2)。
  - 例 3：0.0001x₁ + 2x₂ = 4，x₁ + x₂ = 3。三位浮点不换行得 (0, 2)，换行得 (1, 2)。
  - 部分主元 / 完全主元。
- **§7.4 矩阵范数与条件数**
  - Frobenius 范数；从属范数 max ‖Ax‖/‖x‖。
  - 定理 7.4.2：‖A‖₁ 是最大列和，‖A‖∞ 是最大行和（例 1：14、15）。
  - 定理 7.4.3：‖A‖₂ = σ₁。
  - 例 2：病态。
  - 残差 r = b − Ax′；(1/cond)‖r‖/‖b‖ ≤ ‖e‖/‖x‖ ≤ cond·‖r‖/‖b‖。
  - 例 3 cond∞ = 24；例 4 相对残差 1/18，相对误差 1；cond₂ = σ₁/σₙ；例 5 cond∞ ≈ 6.34 × 10³¹。
- **§7.5 正交变换**
  - ‖Qe‖₂ = ‖e‖₂；Householder H = I − (1/β)vvᵀ。
  - 例 1：x = (1, 2, 2)，α = −3，β = 12，v = (4, 2, 2)，Hx = −3e₁。
  - 例 2：嵌进 4 阶。
  - Householder QR 约 ⅔n³（消元的两倍）。
  - Givens：例 3 x = (−3, 4) → 5e₁（旋转与反射）；例 4 (5, 8, 12) → (13, 8, 0)；约 4/3 n³。
- **§7.6 特征值问题**
  - 不走特征多项式：x¹⁰ 的常数项改 10⁻¹⁰，根从 0 变成模 0.1。
  - 定理 7.6.1：min|λ′ − λᵢ| ≤ cond₂(X)‖E‖₂；对称时 ≤ ‖E‖₂。
  - 幂法：例 1 A = (2 1; 1 2)，u₀ = (2, 1)，λ ≈ 2.98；收敛快慢看 |λ₂/λ₁|ᵏ。
  - Householder 化成上 Hessenberg / 三对角。
  - QR 算法：Aₖ₊₁ = RₖQₖ 与 Aₖ 相似；例 2：A₂ = (2.8 −0.6; −0.6 1.2)，A₃ ≈ (2.976 0.220; 0.220 1.024)。
  - 原点平移加速。
- **§7.7 最小二乘**
  - 正规方程 cond(AᵀA) = cond(A)²。
  - 经典 vs 修正 Gram–Schmidt（算法 7.7.1）。
  - Householder QR：c = Qᵀb，R₁x = c₁，残差 = ‖c₂‖。
  - 伪逆 A⁺ = VΣ⁺Uᵀ；定理 7.7.1：A⁺b 是范数最小的最小二乘解。
  - 奇异值对扰动不敏感；Golub–Kahan 双对角化（点到）。
