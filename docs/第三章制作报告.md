## 2. 各段要点

- **3.1 向量空间是什么**：箭头 → 数组 → 矩阵 → 多项式 → 函数，都能“加”和“数乘”；八条公理（前四条管加法，后四条管数乘）；定理 3.1.1；“不是向量空间”的反例；同济第六章对照卡。
- **3.2a 子空间**：3D 中过原点的平面 / 直线；判定 = 非空 + 加法封闭 + 数乘封闭；不过原点的平面“掉出去”；反例 x₁x₂ = 0；零空间 N(A)。
- **3.2b 张成**：两根不共线箭头扫满 ℝ²，共线时只扫出一条线；Span 的定义；ℝ³ 中两根箭头最多张成平面；Ax = b 的解集 = 特解 + N(A)。
- **3.3 线性无关**：第三根箭头落进前两根张成的平面 → 多余；定义；行列式判定；多项式例题；朗斯基行列式。
- **3.4 基与维数**：基 = 张成（够用）+ 无关（不浪费）；三组基；定理 3.4.1；维数表；P 无穷维；ℝ³ 子空间四类（点 / 线 / 面 / 全空间）；Test B 6（对称矩阵 dim = 3）。
- **3.5 换基**：
  - 开场镜头：标准网格上的点 (7, 7)ᵀ，斜网格 y = (2, 1)ᵀ、z = (1, 4)ᵀ 盖上来以后，同一个点读作 3y + z。结论是“点不变，描述变了”。
  - 新坐标与标准坐标互译：x = Uc，c = U⁻¹x。例 2 算出 (3, −2)ᵀ 并验算。
  - 过渡矩阵：绕标准基走一圈，v 坐标 →V→ 标准坐标 →U⁻¹→ u 坐标，得 S = U⁻¹V。例 4 的 S = [[3, 4], [−4, −5]]，第一列正好是 v₁ 在 u 基下的坐标。
  - **方向陷阱对照卡**：教材 U⁻¹V 与同济 P = V⁻¹U 名字相同、方向相反。期中卷两种写法都出现过，稳妥做法是先写定义式，再验一列。
  - P₃ 换基：3 + 2x + 4x² 在新基下的坐标是 (5, 1, 1)ᵀ。
- **3.6a 行空间与列空间**：
  - 例 1：行空间是 ℝ³ 里的一张平面，列空间是整个 ℝ²，两者维数都是 2。
  - 定理 3.6.1：行变换不改变行空间。
  - 例 2：秩 2。
  - Ax 是各列的线性组合，所以 Ax 能到达的地方就是列空间。3D 画面里 ℝ³ 被压成一张平面，b 在平面上有解，离开平面无解。
  - 定理 3.6.3、推论 3.6.4，以及“可逆 ⇔ det ≠ 0 ⇔ Ax = 0 只有零解 ⇔ 列向量构成基”这条串联前三章的结论链。
  - 例 3、例 4：在 U 里找主元列，回到 A 取同样位置的列。
- **3.6b 秩与零化度**：
  - 每个主元占一行也占一列，所以行秩 = 列秩。
  - 秩–零化度定理。3D 画面里 3×3、秩 2 的矩阵把点阵压成平面，一整条直线被压到原点，对应 2 + 1 = 3。
  - 例 3，以及 Test B 第 7 题：四问配印章。
  - Test B 第 3 题，并给出同济“三秩相等”对照。
  - 四个基本子空间的维数：r、r、n − r、m − r。
- **复习（上）判断题**：Leon Test A 15 题选 12 题（第 5、9、11 题顺带说明）。
  - 大肥鱼抢答 **4 / 12**，左栏答题卡分两列。
  - 最小反例都有画面：两条坐标轴（并集）、3D 平面绕轴转（两张平面必交于一条线）、e₁、e₂、e₁ + e₂（张成但相关）、(1, 1)ᵀ → (1, 0)ᵀ（列空间被行变换改变）、幂零矩阵（秩相同但平方的秩不同）。
  - 收尾总结“反例三大来源”。
- **复习（下）期中真题**：四个套路，每个套路一道题，数字全部经 sympy 复核。
  1. 子空间判定，2021-22：
     - 第 1(3) 题：条件里的“或”实际上是两张平面的并集，反例 (1, 0, 1) + (0, 1, 1) = (1, 1, 2)，3D 画面展示。
     - 第 8 题：x₃ = x₁ − x₂ 写成张成形式，dim = 2。
  2. 线性相关性：y = xC，det C = 2；变式 det = 0；2017-18 多项式版。
  3. 过渡矩阵，2020-21：先写同济约定 (u) = (v)S，S = V⁻¹U，再验第一列；对照卡说明教材约定下答案是 S⁻¹。
  4. 四个基本子空间，2025-26：N(Aᵀ) 由消元记录 5R₁ − 2R₂ + R₃ = 0 读出，再用点积验证它与列空间垂直。

  最后是第三章总结，片尾为“第四章 线性变换”。
