## 0. 起点与主线

- 第二章结尾（s2_xb）预告了「下一章：向量空间」。第三章开头接住：前两章一直在用箭头和数组，这一章问「到底什么东西能叫向量」。
- **双线并行**：
  - **几何线（3B1B）**：子空间 = 过原点的直线 / 平面；张成 = 所有线性组合扫出的区域；线性相关 = 有一根箭头「多余」（落在别人张成的面里）；维数 = 需要几根独立的箭头；换基 = 同一个点在两套网格里的不同坐标。
  - **代数线（Leon）**：八条公理 → 子空间判定（非空 + 加法封闭 + 数乘封闭）→ 线性无关的定义与行列式 / 消元判定 → 基与维数 → 过渡矩阵 → 行空间、列空间、秩与秩–零化度定理。
- 每个概念都给「几何上长什么样」和「考试时怎么判」两种说法；期中卷里本章题量最大（过渡矩阵、四大子空间、相关性几乎每年必考）。

**同济对照提示（由 GPT 在片中点出）**：
- 同济把本章内容拆在第三章（秩）和第四章（向量组）。同济的「向量组的秩」= Leon 的「张成子空间的维数」；同济的「极大无关组」= Leon 的「基」。
- 同济的「线性空间」放在第六章，Leon 一开始就讲抽象向量空间。片中以 Leon 为主线，GPT 提示两边名词对照。
- 过渡矩阵的方向：Leon 写「从 {u} 到 {v} 的过渡矩阵 S，使 [x]_v = S[x]_u」；同济的过渡矩阵 P 满足 (β) = (α)P，**方向相反**。这是期中常见失分点，片中专门放一张对照卡。

## 7. 台本层面的防吞字规则（第二章总结）

- 不在同一句里连着重复长短语（「A的行列式……A的行列式」）。
- 句首不放「短感叹 + ！」（「我来总结！」），改成「让我来总结一下，」接正文。
- 字母串（a、b、c、d）尽量用描述代替。
