## 2. 各段要点

- **2.1a 行列式是什么**：单位正方形 → 平行四边形，割补导出 ad − bc；符号 = 方向（翻面），0 = 压扁（奇异）。
- **2.1b 三阶与展开**：三阶六项式 → 余子式 M_ij / 代数余子式 A_ij → 按第一行展开，3D 体积直观。
- **2.1c 三条推论**：det Aᵀ = det A、三角矩阵 = 对角元乘积、两行相同 / 一行全零 ⇒ 0。
- **2.2a 行变换**：交换 −1、倍乘 α、倍加不变；det(EA) = det E · det A；小测 −3 / 12 / 3 / 24。
- **2.2b 三大结果**：奇异 ⇔ det = 0；消元法求行列式（10! 次乘法 vs 消元，对比柱状图）；det(AB) = det A · det B。
- **2.3a 伴随与克拉默**：adj A、A·adj A = det A · I、克拉默法则 (1, 1, 2)，面积比的几何解释。
- **2.3b 密码与叉积**：SEND MONEY 加密（det = 1 ⇒ 逆矩阵仍为整数）；叉积 = 形式行列式，体积 = 混合积。
- **复习（上）判断题**：Leon Chapter Test A 全 10 题，大肥鱼抢答 3/10 → Claude 逐题讲理由 / 举反例。
- **复习（下）期中真题**：四个套路——拆乘积记指数、含参数令 det = 0、先看结构、余子式组合换行；外加 A² − A − 2I = O 快招。题源：Leon Test B + 本校期中 2015–2024（详见 lines.py 头注释）。

## 4. 引擎修复：大矩阵的竖线（重要）

复习（下）里 4 阶行列式的竖线比数字高出一大截。查下来是 `pipeline/tex_build.mjs` 的老 bug：MathJax 把伸缩定界符（`|…|`、`[…]` 的延伸段）放在**嵌套 `<svg>`** 里、靠视口裁剪来定长，而转换器忽略了嵌套 svg 的 x / y / viewBox，也不裁剪；另外路径包围盒把 `H` / `V` 单参数命令错配成坐标对。

- 修复：按 SVG 语义套用嵌套 svg 的位移 + viewBox 映射，延伸段按「包围盒 ∩ 视口」转成矩形；包围盒改为按命令解析。
- 验证：用 resvg 渲染 MathJax 原始 SVG 作为基准，逐像素对比 —— 第二章 220 个公式，**旧版 47 个有偏差 → 新版 0 个**。
- **第一章影响**：已发布的第一章里有 13 个公式带这个偏差（竖线 / 方括号延伸段位置略偏，多为小矩阵，不明显）：
