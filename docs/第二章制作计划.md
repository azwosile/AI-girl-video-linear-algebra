# 第二章制作计划：行列式（2026-10-22 起草）

主教材 Leon《Linear Algebra with Applications》第 9 版 **Chapter 2 Determinants**（§2.1–2.3，书 p.87–111 / pdf p.104–128）；
对照同济《线性代数》第六版**第一章 行列式**（§1–§5）+ 第二章 §3 逆矩阵、§4 克拉默法则；
学校课件 `第二章PPT/Linear_Algebra_2-{1,2,3}.pdf` 与 Leon 三节一一对应；
画面语言参照 3Blue1Brown《Essence of Linear Algebra》第 6 集（行列式）、第 12 集（克拉默法则的几何解释）。

## 0. 起点与主线

- 第一章结尾（s1_xb）已经预告了「行列式 = 面积放大倍数」，第二章开头接住这句话。
- **双线并行**：
  - **几何线（3B1B）**：行列式 = 变换把面积 / 体积放大多少倍；符号 = 有没有把空间「翻面」；等于 0 = 空间被压扁。
  - **代数线（Leon）**：Leon 用「矩阵能不能消成 I」导出 2×2、3×3 公式，再用余子式递归定义 n 阶。
  - 每个定理都给两种解释：几何上为什么对，考试时怎么算。
- 第一章实际成片 43 分钟，比计划的 65–75 分钟短，因为讲得比较密。第二章按实际语速估时长：全章约 **50–60 分钟**，分 9 段。

**同济对照提示（由 GPT 在片中点出）**：
- 同济用「全排列 + 逆序数」定义 n 阶行列式，Leon 用余子式递归定义。两者等价。片中以 Leon 为主线，只在 s2_1b 放一张「同济的定义长这样」对照卡，不展开逆序数。
- 同济的「对角线法则（沙路法）」只适用于 2 阶和 3 阶。片中强调 4 阶不能这样算，这是常见错误。
- 伴随矩阵同济写作 **A\***，Leon 写作 **adj A**，期中卷两种都出现过（2017-2018 第 1(iii) 写的是 A\*）。片中两种写法并列。
- 同济把克拉默法则放在第二章 §4，Leon 放在 §2.3。

## 3. 复习段选题

**s2_xa Chapter Test A（10 题，答案已核）**

| 题 | 真/假 | 片中给的理由 / 反例 |
|---|---|---|
| 1 det(AB)=det(BA) | 真 | 都等于 det A·det B |
| 2 det(A+B)=det A+det B | 假 | diag(1,0)+diag(0,1)=I：1 ≠ 0+0 |
| 3 det(cA)=c·det A | 假 | det(2I₂)=4 ≠ 2；正确是 cⁿ |
| 4 det((AB)ᵀ)=det A·det B | 真 | 转置不变 + 乘积公式 |
| 5 det A = det B ⇒ A = B | 假 | 两个不同矩阵行列式可以都为 1 |
| 6 det(Aᵏ)=(det A)ᵏ | 真 | 乘积公式重复用 |
| 7 三角阵非奇异 ⇔ 对角元全非零 | 真 | 对角元之积 |
| 8 存在 x ≠ 0 使 Ax = 0 ⇒ det A = 0 | 真 | 有方向被压成 0 |
| 9 行等价 ⇒ 行列式相等 | 假 | 倍乘一行，行列式跟着变 |
| 10 A ≠ O 但 Aᵏ = O ⇒ A 奇异 | 真 | (det A)ᵏ = 0 |
