## 2. 各段要点

- **5.1a 点积**：
  - 标量积 xᵀy = Σxᵢyᵢ，配分量条形图；例 1 结果为 8。
  - 长度与距离：例 2 的距离为 5。
  - 定理 5.1.1 用余弦定理证明，画面中交叉项逐步消去，剩下 xᵀy。
  - 例 3：θ = π/4。
  - 3B1B 看法：点积 = 影子长度 × ‖y‖。x 转动时计量条会变号。
  - 由 |cos θ| ≤ 1 引出柯西–施瓦茨不等式。
  - 正交（例 4）和勾股定律（25 + 9 = 34 的正方形面积）。
  - 应用 1：余弦相似度。
  - 同济对照：内积记号 [x, y]，单位化写成 x/‖x‖。
- **5.1b 投影**：
  - 先把 x 拆成 p + z，再给出 α = xᵀy/‖y‖ 和 p = (xᵀy/yᵀy)y。大肥鱼追问“分母为什么是 yᵀy”，借此讲清楚要除两次 ‖y‖。
  - 例 5：动点沿直线来回扫，距离计停在最小值处，Q = (2.1, 0.7)，垂足就是最近点。
  - 3D 平面方程：例 6、例 7（叉积 N = (6, 1, −8)ᵀ）、例 8（距离 2/3）。
  - Test B 第 1 题：四维投影；验证 1 + 9 = 10。
  - 同济对照：施密特公式中的 [b, a]/[a, a]·a 就是这里的向量投影。
- **5.2 正交子空间**：
  - 例 1、例 2，以及“地板与墙”反例：交线上的向量点积为 1 ≠ 0，所以地板和墙不正交。
  - 正交补 Y⊥：Span(e₁) 的正交补比 Span(e₂) 大。
  - Ax = 0 逐行读，就是“每一行都与 x 正交”，由此得到定理 5.2.1：N(A) = R(Aᵀ)⊥。
  - 例 4 用 3D 一面一线展示，N(A) = Span{(−1, −1, 1)ᵀ}。
  - 定理 5.2.2–5.2.4：维数相加、直和、(S⊥)⊥ = S。
  - Strang 式四子空间大图：A 把行空间一一送到列空间，把零空间压成 0。
  - 推论 5.2.5：Ax = b 二选一。顺势引出最小二乘。
- **5.3a 最小二乘**：
  - 开场是谷神星与高斯：构成主义星空，轨道弧上标出 40 天的观测。
  - 用 3D 列空间平面讲残差 r = b − Ax 的几何意义；定理 5.3.1 用勾股证明。
  - r ∈ R(A)⊥ = N(Aᵀ)，从而得到正规方程 AᵀAx̂ = Aᵀb；定理 5.3.2 讲唯一性；投影矩阵 P。
  - 例 1：x̂ = (83/50, 71/50)ᵀ，验证 Aᵀr = 0。
- **5.3b 数据拟合**：
  - 例 2：y = 4/3 + (2/3)x，残差平方和 2/3。直线可以拖动，残差画成正方形面积，面积和在最佳位置最小。
  - 偏导等于零，推出的正是正规方程。
  - 例 3 抛物线：y = 11/4 − x/4 + x²/4。
  - 高次插值“乱抖”警告。
  - Test B 第 7 题：f = 13/7 + 5x/7。
  - 同济对照：概率统计里回归直线的斜率公式。
- **5.4 内积空间**：
  - 三条公理；ℝⁿ 加权内积。
  - 矩阵内积例 3：⟨A, B⟩ = 6，‖A‖_F = 5。
  - C[a, b] 积分内积：例 1，1 ⊥ x（正负面积抵消），‖1 + x‖² = 8/3。
  - 例 2：cos x ⊥ sin x，引出傅里叶。
  - 一般投影；定理 5.4.2 柯西–施瓦茨的证明。
  - 范数三条；例 5：1 / 2 / ∞ 范数分别为 12、5√2、5，配“单位圆”菱形、圆、正方形变形动画。
- **5.5 标准正交基**：
  - 例 1、例 2。
  - 定理 5.5.1：正交 ⇒ 线性无关。
  - 定理 5.5.2：坐标 = 内积，画面中 v 往每根轴上投影。
  - 帕塞瓦尔恒等式；例 5 把 ∫sin⁴x 变成勾股定理，结果 3π/4。
  - 正交矩阵 QᵀQ = I：网格做刚性转动（与第四章的剪切对照）；置换矩阵。
  - p = UUᵀb：例 7 (5, 3, 4) → (5, 3, 0)。
  - Test B 第 8 题：‖x‖ = 3。
  - 同济对照：AᵀA = E，正交变换，|A| = ±1。
- **5.6 施密特与 QR**：
  - 3D 中逐个“减影子再单位化”。为什么不会减成零向量？span 始终保持不变。
  - 例 2：q 全是 ±1/2；R = [[2, 3, 2], [0, 5, −2], [0, 0, 4]]，系数逐个落进上三角。
  - 定理 5.6.2 A = QR；定理 5.6.3 Rx̂ = Qᵀb。
  - 例 4 回代：x̂ = (−2/5, 0, 1)ᵀ。顺带提到修正施密特。
  - 1、x、x² → 正交多项式（5.7）。
  - 同济对照：先全部正交化再单位化，记号 [b, a]/[b, b]。例题 b₂ = (5/3)(−1, 1, 1)ᵀ，b₃ = (2, 0, 2)ᵀ。
- **复习（上）判断题**：Test A 全 10 题，大肥鱼答对 **6 / 10**，左栏答题卡分两列。
  - 正确答案：1F 2F 3F 4F 5T 6F 7T 8T 9T 10F。
  - 错题都配了最小反例：
    - 第 1 题：投影不能交换，(1, 1) 与 (1, 0) 互投。
    - 第 2 题：等号成立意味着两向量共线。
    - 第 3 题：三根轴。
    - 第 6 题：3D 中 x̂ 不唯一，但 p 唯一。
    - 第 10 题：UUᵀ 是投影矩阵，(5, 3, 4) 被压成 (5, 3, 0)。
  - 收尾总结错题的共同点：把公式当成对称的、可以交换的。
- **复习（下）计算题**：
  - Test B 第 4 题：四子空间维数 3 / 1，‖x‖ = 0，最小二乘有无穷多解。
  - Test B 第 6 题：S⊥ = Span{(−2, 2, 1)ᵀ}，P = nnᵀ/9。
  - Test B 第 10 题：补完 QR，Qᵀb = (1, 6, 6)ᵀ，x̂ = (7/4, 3/4, 1)ᵀ。
  - 同济题型一“求两两正交的向量”：零空间 + 施密特，a₂ = (1, 0, −1)ᵀ，a₃ = (−½, 1, −½)ᵀ。
  - 同济题型二“判断正交矩阵”：(1/9)[[1, −8, −4], …]。
  - 最容易丢分的两处、整章一句话“垂直 = 最近”，最后预告第六章特征值。
  - **没有编造“某年考过”**。
