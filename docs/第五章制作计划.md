## 0. 起点与主线

**一句话主线：垂直 ⇒ 最近。** 点积给出长度和角度；投影的垂足是最近点；把 b 投影到列空间就是最小二乘；有了标准正交基，投影只要做内积；施密特过程把任意基掰成标准正交基，顺手得到 A = QR。

**几何线（3B1B）**
- 点积 = 影子长度 × ‖y‖：x 绕原点转一圈，点积计量条跟着正、零、负。
- 向量投影：垂足、影子、最近点（例 5 直线 y = x/3）。
- 子空间正交：3D 里一面一线（例 4 的行空间平面 + 零空间法线）；四个基本子空间大图。
- 最小二乘：3D 里 b 悬在列空间平面上方，垂线落下；拟合时残差竖线 → 残差方块面积最小。
- 范数单位球：圆 / 菱形 / 正方形。
- 正交矩阵：网格刚性转动，格子不拉伸。
- 施密特：一根一根“减掉影子再拉直”，3D 里 x₃ 减去在平面上的投影。

**代数线（Leon）**
- 定理 5.1.1 xᵀy = ‖x‖‖y‖cos θ；柯西–施瓦茨；勾股定律；投影 p = (xᵀy / yᵀy)y。
- 定理 5.2.1 N(A) = R(Aᵀ)⊥、N(Aᵀ) = R(A)⊥；定理 5.2.2–5.2.4；推论 5.2.5。
- 定理 5.3.1 最近点 ⇔ b − p ⊥ S；正规方程 AᵀAx = Aᵀb；定理 5.3.2；投影矩阵 P = A(AᵀA)⁻¹Aᵀ。
- §5.4 内积三条公理、C[a, b]、F 范数、定理 5.4.2 柯西–施瓦茨、范数三条、1 / 2 / ∞ 范数。
- §5.5 定理 5.5.1、5.5.2（坐标 = 内积）、帕塞瓦尔、正交矩阵 QᵀQ = I、定理 5.5.6、5.5.7–5.5.8、推论 5.5.9 p = UUᵀb。
- §5.6 定理 5.6.1 施密特、5.6.2 QR、5.6.3 Rx = Qᵀb。

**和前几章的接口（片中点明）**
- 第三章零空间 / 行空间 / 列空间 → 定理 5.2.1 把它们配成两对正交补；秩–零化度 → dim S + dim S⊥ = n。
- 第四章“限制在行空间上 A 是一一对应”。
- 第一章“无解”的方程组 → 最小二乘给出“最好的近似解”。

  - `perp[] {S, comp}`：comp 与 S 的每个向量正交且维数互补
