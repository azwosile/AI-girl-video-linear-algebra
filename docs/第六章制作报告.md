## 2. 各段要点

- **6.1a 方向不变的向量**
  - 开头回扣第一章的婚姻例子：8000/2000 每年乘一次 A，第 12 年起停在 (4000, 6000)。人数用条形图逐年演示。
  - 把起点拆到两个特殊方向：x₁ = (2, 3)ᵀ 乘完不动，x₂ = (−1, 1)ᵀ 乘完减半，所以 wₙ = 2000x₁ − 4000(½)ⁿx₂ → (4000, 6000)。
  - 定义 Ax = λx（x ≠ 0）。用 3B1B 网格变形展示：大多数向量离开原来的直线，只有特征线上的向量只伸缩。
  - 例 2：λ = 3，特征向量的非零倍数还是特征向量（整条直线）。
  - 零向量为什么排除；(A − λI)x = 0、特征空间、特征方程。
  - 五条等价。
  - 同济对照：|A − λE| = 0，特征值可以为 0。
- **6.1b 特征多项式、迹与行列式**
  - 例 3：λ = 4、−3。把 λ 当滑块，面积缩放因子 det(A − λI) 扫过 0 的位置就是特征值。
  - 例 4：三阶二重根，λ = 1 的特征空间是一个平面，在 3D 中展示。
  - 例 5：旋转没有实特征方向，λ = 1 ± 2i，特征值共轭成对。
  - 积 = det、和 = tr。例 6：13 与 4 的验算。
  - 定理 6.1.1：相似矩阵的特征多项式相同（例 7：T 与 S⁻¹TS）。
  - 同济对照：λ² 是 A² 的特征值，φ(λ) 是 φ(A) 的特征值，1/λ 是 A⁻¹ 的特征值。
- **6.2 线性微分方程组**
  - 从 y′ = ay 出发，试 Y = e^(λt)x，得到 Ax = λx。
  - 例 1：λ = 6、−1。用相平面流线展示：沿 x₁ 向外冲，沿 x₂ 往回收。
  - 初值 (6, 1)：y₁ = 4e⁶ᵗ + 2e⁻ᵗ，y₂ = 3e⁶ᵗ − 2e⁻ᵗ。
  - 复特征值 2 ± i：向外的螺线；实部为负时向里旋，系统稳定。
  - 弹簧（简谐运动）：纯虚特征值，相平面上是一个圆。
  - 同济对照：常系数方程组的特征根法。
- **6.3a 对角化**
  - 定理 6.3.1、定理 6.3.2，AX = XD 按列对应。
  - 例 1：用基变换的眼光看，在特征基里只沿两轴伸缩。A⁵ = (206 −615; 410 −1229)。
  - 例 2：有重根也能对角化。
  - 例 3：剪切变换亏损，只有一条特征线。
  - 例 4：A 与 B 的代数重数和几何重数用条形图对比，配“亏损 / 可对角化”印章。
  - 同济对照：P⁻¹AP = Λ 的求法步骤。
- **6.3b 马尔可夫链与矩阵指数**
  - 婚姻链：随机矩阵，稳态 (0.4, 0.6)，状态一步步落到稳态线上。定理 6.3.3。
  - 应用：租车四状态；网页排名，节点大小 = 稳态分量。
  - 矩阵指数：eᴬ 的级数，eᴬ = XeᴰX⁻¹（例 6）。Y = eᵗᴬY₀（例 7，与 6.2 的结果相同）。
  - Aⁿ ⟷ eᵗᴬ 对照。
  - 同济对照：求 φ(A) = A¹⁰ − 5A⁹。
- **6.4 对称矩阵与谱定理**
  - 复向量长度 zᴴz；埃尔米特矩阵；定理 6.4.1（特征值为实数，不同特征值的特征向量正交）的证明。
  - 酉矩阵；谱定理 6.4.4 A = QDQᵀ，并推出 Schur 定理。几何上：沿互相垂直的轴伸缩，不会剪歪。
  - 例 4：λ = −1, −1, 5。重根平面内做施密特正交化，λ = 5 的特征向量自动与该平面垂直（3D 展示）。
  - 正规矩阵。
  - 同济对照：P⁻¹AP = PᵀAP = Λ 的经典题，λ = −2, 1, 1。
- **6.5 奇异值分解**
  - 单位圆 → 椭圆：A = (3 0; 4 5)，σ = 3√5, √5。v₁ ⊥ v₂ 经过 A 后仍有 Av₁ ⊥ Av₂。
  - A = UΣVᵀ：转 · 拉 · 转。σᵢ = √λᵢ(AᵀA)。
  - 例 1（3×2，σ = 2, 0）：秩 = 非零奇异值个数。
  - 低秩逼近（定理 6.5.3）：40×40 图像保留前 30 层，并画出奇异值衰减条形图。
  - 应用：数值秩、潜在语义索引、主成分分析。
  - 同济对照：同济不讲 SVD，特征分解与 SVD 并排对比。
- **6.6 二次型**
  - xᵀAx，A 为对称矩阵。例 2：3x² + 2xy + 3y² = 8，λ = 2、4，转 45° 后变成 x′²/4 + y′²/2 = 1。
  - 主轴定理 6.6.1。正定 / 负定 / 不定分别画成碗、倒碗、马鞍三张曲面。定理 6.6.2。
  - 黑塞矩阵判极值：Test B 第 6 题，λ = 5、−1，是鞍点。
  - 同济对照：正交变换法与配方法、惯性定理。
- **6.7 正定矩阵**
  - 例 1：A = (4 2 −2; 2 10 2; −2 2 5)。
    - 顺序主子式 4、36、108；
    - 主元 4、9、3（Δₖ = 前 k 个主元的乘积）；
    - A = LDLᵀ → Cholesky L₁ = (2 0 0; 1 3 0; −1 1 √3)。
  - 定理 6.7.1 五条等价。陷阱：−I₂ 的 det = 1 > 0，但它是负定；半正定要看全部主子式。
  - 6.8 点到：Perron 定理，正矩阵有正特征向量，用于投入产出模型、马尔可夫链和网页排名。
  - 同济对照：赫尔维茨定理；含参题 −4/5 < a < 0。
- **复习（上）判断题**
  - 题目：Test A 第 1–9、14 题，共 10 道。大肥鱼答对 **6 / 10**。
  - 正确答案：1T 2F 3T 4F 5F 6F 7F 8F 9T 14F。
  - 大肥鱼错在第 2、5、7、8 题，每道都配了最小反例：剪切、I、−I、(0 1; 0 0)。
  - 收尾总结错题的共同点：把“可能”当成了“一定”，根源都是亏损矩阵。
- **复习（下）计算题、同济题型与小结**
  - Test B 第 1 题：A⁷ = A，D⁷ = D。
  - Test B 第 5 题：LDLᵀ 与 Cholesky，因子全是整数。
  - Test B 第 7 题：Y′ = AY 的初值问题，两个负特征值，解衰减到 0。
  - 同济三类题型：
    - 不可对角化：r(A − E) = 2；
    - 可对角化：r(A − 2E) = 1；
    - 正交变换化标准形：f → −2y₁² + y₂² + y₃²。
  - 全章用一张树状图串起来：Ax = λx → 对角化 → 对称 → 二次型 / SVD。最后预告第 7 集数值线性代数。
  - **没有编造“某年考过”**。
