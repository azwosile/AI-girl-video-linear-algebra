## 0. 起点与主线

**一句话主线：找到不转向的方向，矩阵就只剩伸缩。** 特征向量是变换后方向不变的向量，特征值是伸缩倍数；有 n 个无关的特征向量就能对角化，于是 Aᵏ、e^{tA}、马尔可夫稳态都只是“对角线上各自乘方”；对称矩阵更好——特征向量两两正交，可以用正交矩阵对角化，二次型由此转到主轴；非方阵则用 SVD：单位圆 → 椭圆。

**几何线（3B1B）**
- 网格变形时，大多数向量离开自己的直线，只有特征方向上的向量留在原线上，只被拉长 / 缩短 / 反向。
- 特征多项式：det(A − λI) 把 λ 当滑块，面积缩放因子扫过 0 的位置就是特征值。
- 旋转矩阵没有实特征方向 → 复特征值。
- 微分方程组：相平面流线，沿特征方向直进直出（6 与 −1：一条向外冲，一条往里收）。
- 对角化：换到特征基 → 网格只沿两轴伸缩 → 再换回来。剪切矩阵只有一条特征线（亏损）。
- 马尔可夫：状态向量一步步落到稳态直线上，(1/2)ⁿ 分量衰减。
- 谱定理：对称矩阵的两条特征线互相垂直，网格变形 = 沿垂直轴伸缩。
- SVD：单位圆 → 椭圆，V 的列转到 U 的列，长度 σ。
- 二次型：等高线椭圆被旋转；转到主轴后交叉项消失；正定 = 碗，不定 = 马鞍。
- Cholesky：A = LLᵀ，消元三步“剥洋葱”。

**代数线（Leon）**
- §6.1 定义 Ax = λx；(A − λI)x = 0；特征空间 N(A − λI)；特征方程 det(A − λI) = 0；例 2–7；λ₁⋯λₙ = det A，Σλᵢ = tr A；定理 6.1.1 相似矩阵特征多项式相同。
- §6.2 Y′ = AY，Y = c₁e^{λ₁t}x₁ + c₂e^{λ₂t}x₂；例 1（λ = 6、−1，初值 (6, 1)ᵀ → 4e^{6t} + 2e^{−t}，3e^{6t} − 2e^{−t}）；复特征值 → e^{at}(cos bt, sin bt) 螺线；应用：简谐运动。
- §6.3 定理 6.3.1 不同特征值的特征向量线性无关；定理 6.3.2 可对角化 ⇔ n 个无关特征向量；Aᵏ = XDᵏX⁻¹；亏损矩阵；代数重数 / 几何重数（例 4 的 A、B）；马尔可夫链与稳态（定理 6.3.3）；PageRank；矩阵指数 e^A = Xe^DX⁻¹，Y = e^{tA}Y₀（例 6、例 7）。
- §6.4 复内积 zᴴz；埃尔米特矩阵 M = Mᴴ；定理 6.4.1 特征值全为实数、不同特征值的特征向量正交；酉矩阵；Schur 定理（点到）；**谱定理 6.4.4**；实对称矩阵 A = QDQᵀ（例 4）；正规矩阵（点到）。
- §6.5 SVD 定理 6.5.1 A = UΣVᵀ；σᵢ = √λᵢ(AᵀA)；例 1；秩 = 非零奇异值个数；定理 6.5.3 最佳低秩逼近；应用：数值秩、图像压缩、主成分分析。
- §6.6 二次型 xᵀAx；例 2 圆锥曲线 3x² + 2xy + 3y² = 8 转主轴；主轴定理 6.6.1；正定 / 负定 / 不定；定理 6.6.2 正定 ⇔ 特征值全正；驻点与黑塞矩阵。
- §6.7 定理 6.7.1 五条等价（正定、顺序主子式全正、主元全正、Cholesky、BᵀB）；例 1–3 LU → LDLᵀ → LLᵀ。
- §6.8 非负矩阵：Perron 定理、投入产出模型（只在 s6_7 结尾点到）。

**同济对照（GPT 主讲）**
- §2：特征值记号相同；同济习惯写 |A − λE| = 0（单位阵记作 E），计算题常见 3 阶；性质 λ₁λ₂⋯λₙ = |A|、Σλᵢ = tr A；例：A = (−1 1 0; −4 3 0; 1 0 2)，λ = 2, 1, 1，但 λ = 1 只有一个无关特征向量。
- §3：相似矩阵、相似对角化条件；例 A = (−2 1 1; 0 2 0; −4 1 3)，λ = −1, 2, 2，λ = 2 有两个无关特征向量 → 可对角化。
- §4：对称矩阵一定可以用正交矩阵对角化（同济“正交变换”说法）；例 A = (0 −1 1; −1 0 1; 1 1 0)，λ = −2, 1, 1，重根要先施密特正交化。
- §5–§6：二次型的标准形、规范形，正交变换法与配方法；惯性定理。
- §7：正定判定：顺序主子式全正（赫尔维茨定理）；含参题：x₁² + x₂² + 5x₃² + 2ax₁x₂ − 2x₁x₃ + 4x₂x₃ 正定 ⇔ −4/5 < a < 0。
- 同济不讲：微分方程组、马尔可夫、矩阵指数、复矩阵、SVD、Cholesky、非负矩阵。
