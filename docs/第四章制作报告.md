## 2. 各段要点

- **4.1a 线性变换是什么**：
  - 定义：保持加法与数乘（一条式子 L(αv₁ + βv₂) = αL(v₁) + βL(v₂)）。
  - 几何直觉：网格保持平行等距、原点不动。
  - 例 1–4：伸缩 3 倍、投影到 x₁ 轴、关于 x₁ 轴反射、逆时针转 90°，都用网格变形演示。
  - 反例：例 6 的 ‖x‖、Test B 第 1(b) 题，以及平移（原点被挪走）。
- **4.1b 核与像**：
  - 例 7：ℝ² → ℝ³，3D 画面里平面被送进三维空间；A = [[0, 1], [1, 0], [1, 1]]。
  - L(0) = 0、保持线性组合等三条性质；平移就这样出局。
  - 核与像的定义，用 V / W 两个色块示意。
  - 例 11：ker = x₂ 轴；例 12：ker = Span{(1, −1, 1)ᵀ}，S 的像是整个 ℝ²；例 13：P₃ 上的求导。
  - 秩–零化度定理换一种说法：核的维数 + 值域的维数 = 输入空间的维数。
- **4.2a 标准矩阵**：
  - 盯住 î 和 ĵ：î → (1, −2)，ĵ → (3, 0)，x = (−1, 2) 落到 (5, 2)。
  - 例 1：[[1, 1, 0], [0, 1, 1]]；旋转矩阵；Test B 第 5 题 [[1, 1], [1, −1], [3, 2]]。
  - Test B 第 2 题：不求矩阵，直接拆 v₃ = 3v₁ + 2v₂，得 L(v₃) = (0, 17)。
  - 复合 = 矩阵乘积，先做的写右边：剪切 · 旋转 90° = [[1, −1], [1, 0]]。
  - Test B 第 6 题：FR ≠ RF，变换的顺序不能换。
- **4.2b 任意基下的矩阵**：
  - 定理 4.2.2 的交换图：上面走 L，下面走 A，两条路的终点重合。
  - aⱼ = L(vⱼ) 在 F 下的坐标；例 3–6 逐题走交换图。
  - 例 5：P₃ 上的求导，A = [[2, 0, 0], [0, 1, 0]]。
  - 同济对照：同济只讲 V → V 用同一组基；英文教材允许输入、输出各用一组基。
- **4.2c 计算机图形学**：
  - 伸缩 1.5 倍、关于 y 轴反射、旋转 60°。
  - 平移不是线性变换，所以引入齐次坐标：提升到 z = 1 平面，再在 3D 里做剪切，平移就变成了矩阵乘法。
  - 复合矩阵 [[1.5, 0, 6], [0, 1.5, 2], [0, 0, 1]]；Test B 第 7 题 [[1, 0, 2], [0, 1, 5], [0, 0, 1]]。
  - 思考题：{(x, y, 1)ᵀ} 是不是 ℝ³ 的子空间？（复习上第 5 题揭晓。）
- **4.3 相似**：
  - 开场是“两副眼镜”：同一个 L，标准网格读出 A = [[2, 0], [1, 1]]，u-网格读出 B = [[2, −1], [0, 1]]。
  - 翻译链 U → A → U⁻¹ 得 B = U⁻¹AU；接着是定理 4.3.1 的交换图和相似的定义，再讲对称性、传递性。
  - 例 1：P₃ 求导，S = [[1, 0, −2], [0, 2, 0], [0, 0, 4]]，A = S⁻¹BS。
  - 例 2：3D 画面中三根新坐标轴分别 ×0、×1、×4，得到 diag(0, 1, 4)，顺带预告对角化。
  - 不变量：相似矩阵迹相同、行列式相同（Test B 第 10 题）。
  - **同济对照（名字方向相反）**：Leon 的 S 与同济的 P 公式都写 S⁻¹AS，但“从哪到哪”的叫法相反。这一点接住第三章的方向陷阱。
- **复习（上）判断题**：Leon Test A 全部 10 题。
  - 大肥鱼抢答 **5 / 10**，左栏答题卡分两列。
  - 每道错题都配最小反例画面：
    - 第 1 题：投影把 (1, 2)、(1, 5) 都压到 (1, 0)。
    - 第 4 题：î 先转后反射与先反射后转，落点不同。
    - 第 5 题：3D 里 z = 1 平面不过原点，而且加法跑到 z = 2。
    - 第 10 题：I 与 diag(2, 0) 迹相同，但不相似。
  - 第 3 题配沿核滑动的网格，第 7 题点出“基向量的去向决定一切”是整章的地基。
- **复习（下）计算题 + 同济题型**：
  - GPT 开场说明：翻了 9 份期中卷，线性变换很少出现，主要考在期末。所以这一节用 Test B 精选加同济期末常见题型，**不编造“某年考过”**。
  - Test B 第 3 题：套路卡①求核、②求像。
  - Test B 第 4 题：套路卡③把值域写成方程 y₃ = y₁ + y₂，3D 画面里 ℝ³ 被压到这张平面上，1 + 2 = 3。
  - Test B 第 9 题：v 坐标 →V→ 标准坐标 →U⁻¹→ u 坐标，得 S = U⁻¹V = [[12, 7], [−7, −4]]，再验一列。B = S⁻¹AS = [[−222, −131], [383, 226]]，用迹 4、行列式 1 秒验。
  - 同济期末“相似求参数”：迹、行列式两个等式解出 x = 0、y = 1。同时强调这只是必要条件，用来解参数可以，不能用来证明相似；最后代回去，用交换块的 2D 网格验证。
  - 第四章五条总结，一句话收束：“矩阵 = 线性变换在一组基下的坐标写法”。片尾预告第五章 正交性。
