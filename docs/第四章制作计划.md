## 0. 起点与主线

这一章是整套课 **3B1B 味道最浓** 的一章，前三章埋下的东西都在这里收束：
- 第一章 Ax：解方程组。
- 第二章 AB：矩阵乘法。
- 第三章 N(A)、列空间、过渡矩阵。

第四章把它们统一成一句话：**矩阵就是线性变换在一组基下的坐标写法。**

**几何线（3B1B）**
- 线性变换的判别：网格线保持平行且等距，原点不动。
- 标准矩阵：盯住 î、ĵ 落在哪里，这两列就是矩阵。
- 复合就是矩阵乘法，而且先做的写在右边。
- 核：被压到原点的那部分。值域：整张网格被压成的那个子空间。
- 相似：同一个变换，换一副“眼镜”（基）去看，写下来的矩阵就不一样。

**代数线（Leon）**
- 定义：L(αv₁ + βv₂) = αL(v₁) + βL(v₂)。
- 核与像，定理 4.1.1。
- 定理 4.2.1：aⱼ = L(eⱼ)。
- 定理 4.2.2：[L(v)]_F = A[v]_E。
- 定理 4.2.3 与推论 4.2.4：对 (B | L(u₁) … L(uₙ)) 做行化简，得到 (I | A)。
- 定理 4.3.1：B = S⁻¹AS。
- 相似的定义，以及相似矩阵的不变量：det、迹。

**和第三章的接口（片中由 Claude 点明）**
- ker(L) ↔ N(A)。
- L(V) ↔ 列空间。
- 秩–零化度定理 ↔ dim ker + dim 值域 = dim V。
- 第三章的过渡矩阵 S，在 B = S⁻¹AS 里第二次登场。

**Test A 真值（10 题）**：1F 2T 3T 4F 5F 6T 7T 8T 9T 10F。
- 1：L 可以不是单射，例如投影。

## 4. 同济对照卡（GPT 出场）

1. **名词对照**：
   - 核 ker L = 同济的“核 T⁻¹(0)”。
   - 像 / 值域 L(V) = 同济的“像空间 T(Vₙ)”。
   - 同济线性变换只讲 Vₙ → Vₙ，也就是 Leon 的“算子”。
2. **相似公式方向**：
   - Leon 的 S 是“从 F 到 E 的过渡矩阵”，列 = 新基在旧基下的坐标。
   - 同济的 P 满足 (β) = (α)P，列也 = 新基在旧基下的坐标。
   - 所以 **两边是同一个矩阵，公式都写 B = S⁻¹AS（同济 B = P⁻¹AP），只是名字的方向相反**。
   - 这正好接住第三章 s3_5 的方向陷阱。片中强调：“公式一样，名字相反；照样先写定义式再验一列。”
3. **相似的位置**：同济把相似放在第五章特征值之后，Leon 先在第四章讲相似、第六章再讲特征值。片中预告：“例 2 的 diag(0, 1, 4) 不是巧合，第六章揭晓。”

## 7. 工序（与第三章相同，吸取第三章教训）
