## 3. 构图

- **大圆舞台**：每个场景有一个 `peri` 大圆（直径约 0.7 H），作为视觉焦点与数学区背景，可以移动或缩放来转场。
- **数学区 ≥ 60%**：坐标系、矩阵、公式放在大圆内或跨越大圆。
- **角色**：讲解时缩到左下或右下（高约 0.45 H），或收进小圆窗；提问、反应、开场时放大到半身（高约 0.9 H），数学区同时让位。
- **细线与星点**：左上角竖线 + 四角星作为段落标识（参考图左上）；底部是加点衬线标题 `— L.I.N.E.A.R. —` 风格的段名。
- **无卡片**：定义、定理直接用 TeX 写在纸面上，最多加一条 `ink` 细线下划或左侧竖线，**不用圆角框**。教材原文 Tip 例外：用一块斜切的 `paper_hi` 纸片，带出处。

## 5. 角色立绘（Arena 生图规范）

- **风格**：与参考图一致：三色平涂剪影，硬边，无渐变，无描线阴影，背景纯 `#EDE7DA` 或纯绿底（便于抠图）。
- **每位角色有一套专属三色**（都与 `ink` 共享暗部）：
  - Claude：赤陶 `#C8643C` / 浅杏 `#E9B79A` / ink（白花、书本）
  - GPT：墨绿 `#2F6B5A` / 薄荷灰 `#A9C9BD` / ink（白发龙角、龙尾）
  - 大肥鱼：长春花蓝 `#748DD8` / 雾蓝 `#ABB5DE` / ink（猫耳女仆、鲸鱼发饰），**即参考图本身**
- **姿势**：每人 6–8 张：讲解、指向右、思考、惊讶、得意、双手合十（参考图）、举手提问、点头。
- **分层**：每张导出后拆成身体 / 头 / 眼（睁、半、闭）/ 嘴（闭、半、开）/ 前臂，供 `cast/` 做眨眼、口型、呼吸（±0.6% 缩放）、剪纸式入场（旋转 ±4° 加位移，带纸片阴影）。
- 每张图都要检查：手指数、头顶完整、和原设定（`ai-girls/characters/*`）的辨识特征一致。

## 6. 运动语言

- **缓动**：默认 `smooth`（3B1B 的 `smoothstep` 变体），入场 `back.out(1.2)` 只用于角色和纸片，数学对象不回弹。
- **转场**：大圆缩放擦除 / 斜切色块（参考图里的角度，约 −18°）/ 纸片翻转。每段 ≤ 1 种主转场。
- **镜头**：允许推拉平移（数学区放大到某个矩阵元素），每次 ≥ 0.8 s，禁止抖动。
- **禁止**：发光、星空、霓虹；高频闪烁；同屏 > 3 种强调色；画面静止讲话 > 2 s。
