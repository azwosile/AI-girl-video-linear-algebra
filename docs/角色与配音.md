## 朗读稿规则（线代专用，台词源里字幕与朗读分开写）

| 字幕 | 朗读 |
|---|---|
| `A^{-1}` | A 的逆 |
| `A^T` | A 转置 |
| `\mathbf{v}` | 向量 v |
| `\hat{\imath}`, `\hat{\jmath}` | i hat、j hat（试读，读错改写为「i 帽」「j 帽」） |
| `\mathbb{R}^3` | R 三 |
| `m\times n` | m 乘 n |
| `a_{ij}` | a i j |
| `\det A` | A 的行列式 |
| `R_2 \leftarrow R_2 - 3R_1` | 第二行减去三倍第一行 |
| `(A-\lambda I)\mathbf{x}=\mathbf{0}` | A 减 lambda I，乘 x 等于零向量 |
| `\operatorname{rank}A` | A 的秩 |
| `N(A)` | A 的零空间 |

字母读错的，改写成谐音并记入本表。
